##  About The Project

From **Android Developer** to **Mobile AI Engineer** —
this project is one of the first steps in that journey.

The idea is simple:

> Give the app your dataset → Analyze it → Get meaningful visualizations.

The goal wasn't just to build another project.

I wanted to build something that could **actually help people** make their data easier to understand.

And yes...

### 🆓 It's completely free. 😅😉
